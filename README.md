# Peters Parking

## Sobre o projeto

O **Peters Parking** é um projeto desenvolvido com o objetivo de melhorar a organização e o gerenciamento de um estacionamento por meio de um sistema digital. A proposta busca facilitar o controle de veículos, clientes, entradas e saídas, além de disponibilizar informações importantes para os funcionários e gerentes.

## Principais funcionalidades

### Gerente

* Cadastrar funcionários no sistema.
* Acessar relatórios relacionados ao estacionamento.

### Funcionário

* Registrar clientes.
* Registrar a entrada e a saída de veículos.
* Gerar relatórios.
* Consultar as vagas disponíveis por meio do aplicativo.
* Visualizar fotos dos veículos.
* Acessar informações dos clientes para verificar se irão retirar seus veículos.

## Objetivo do projeto

Centralizar as informações do estacionamento em um sistema, facilitando o acompanhamento dos veículos, a consulta de vagas disponíveis e o gerenciamento das atividades realizadas pelos funcionários e pelo gerente.
